# @mox/auth-backend

Aplicación auth en TypeScript. Requiere Node 24.22.0 y pnpm 10.34.7.

Node 24 se gestiona con nvm. Desde la raíz del repositorio ejecutar `nvm install`
y `nvm use` para usar la versión fijada en `.nvmrc`.

Desde la raíz: `pnpm --filter @mox/auth-backend build` y `pnpm --filter @mox/auth-backend typecheck`.
